# Valenced Plugins & Themes

All of dariuss' Valenced plugins and the Midnight mobile theme in one repository, based on the [official Valenced plugin template](https://github.com/Valenced/valenced-plugin-template).

## Install

Add this single URL in **Valenced Settings → Plugins → Advanced → Repository URL**:

```text
https://raw.githubusercontent.com/dariussbezy/dariussbezy-Valenced-Plugins-Themes/main/index.json
```

Choose the plugins you want from the **beta** channel. Existing plugin IDs and versions are preserved. You can remove the old individual repository entries from Valenced after adding this repository; installed plugin settings remain associated with their existing IDs. Restart Discord after updates when requested.

## Repository structure

- `plugins/`: QT, JTP, PM, SHC, VMTT and LGD. Each plugin has its own manifest, `js/` sources and TypeScript project.
- `themes/MT/`: Midnight's mobile implementation, local assets and original desktop CSS.
- `pool/`: the installable ZIPs; `index.json` is generated by the official CLI.
- Root configuration: shared template Gradle wrapper, compiler, type settings and GitHub Actions. No demonstration plugins are included.

Install dependencies using `bun install --frozen-lockfile`. `bun run build:all` compiles the JavaScript, `bun run lint:types` checks every project and `bun run test` runs the tests. `./gradlew packageAllPlugins` packages every plugin. `bun run publish:local` copies freshly packaged artifacts into the pool and regenerates the single index. Sources and distribution are maintained on `main`.

The VMTT Android component is under `plugins/VMTT/src/main/java`. Its existing native JAR is preserved. A fresh native build needs the real Valenced SDK, either published to your local Maven repository or accessed with the `READ_PACKAGES_TOKEN` secret as documented by the official template. The token is for compiling, not installing plugins.
