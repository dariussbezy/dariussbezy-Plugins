# dariussbezy's Plugins

Plugins and a theme for Valenced on Discord mobile (Android and iOS).

## Install

Add this URL in **Settings → Plugins → Settings Icon → Repository URL**:

```text
https://raw.githubusercontent.com/dariussbezy/dariussbezy-Plugins/main/index.json
```

Install from the **latest** channel and enable **Allow updates**.

## Plugins

| Name | Description |
| --- | --- |
| [Adv. Message Logger](plugins/AML/README.md) | Keep a local journal of edited and deleted messages, keep them visible in chat and compare edits. |
| [Better Toasts](plugins/BT/README.md) | Choose how long toasts stay, and add replace, pause, swipe to dismiss, tap to copy and a history of recent toasts. |
| [Custom Quick Reactions](plugins/CQR/README.md) | Choose and reorder the quick reaction emojis shown when you long-press a message. |
| [Ghost Ping Logger](plugins/GPL/README.md) | Find mentions and replies that were deleted or edited away and get alerted. Requires Adv. Message Logger. |
| [Jump to Ping](plugins/JTP/README.md) | Jump to unread mentions, replies and DMs from a button beside the notifications bell. |
| [Message Actions](plugins/MA/README.md) | Reorder, hide or remove the buttons shown when you long-press a message. |
| [Music Controls](plugins/MC/README.md) | Control Spotify, YouTube Music and SoundCloud from a player above the YouBar. YouTube Music and SoundCloud need the Android app. |
| [No Delete Confirmation](plugins/NDC/README.md) | Delete messages without the confirmation dialog. |
| [No Onboarding Delay](plugins/NOD/README.md) | Skips the slow waits in server onboarding. |
| [No Tap Mention](plugins/NTM/README.md) | Disable tapping a message author's name to insert a mention. |
| [Performance Monitor](plugins/PM/README.md) | See how much time each plugin takes and find the ones that slow Discord down. |
| [Quick Translate](plugins/QT/README.md) | Translate messages and drafts with Google, Microsoft, DeepL or Groq AI. |
| [Show Blocked](plugins/SB/README.md) | Show messages from blocked and ignored users as normal messages, with options for pings, DMs and exclusions. |
| [Transparent YOUBAR](plugins/TY/README.md) | Make the YouBar transparent, in the same style as the Music Controls player. |
| [Voice Messages To Text](plugins/VMTT/README.md) | Transcribe voice messages below the audio, with a free server or Groq. |
| [Midnight Mobile](themes/MT/README.md) | Midnight for Discord mobile: navy panels, blue accents, Figtree and the moon icon. |

Midnight's colors, Figtree font and moon icon are selected under **Settings → Themes**. Font and icon changes require a restart.
